# Contrôle des références du rapport cabinet

Fiche à signer, une source à la fois. Une référence ne passe à « source contrôlée » que lorsqu'une personne qualifiée a vérifié les **deux** points ci-dessous et l'a signée ; aucun outil ne peut le faire à sa place.

1. **Identification** : la source existe telle que citée. Pré-vérifié par une base bibliographique indépendante (Crossref pour les articles, Open Library pour les livres) le 23/10/2026 ; voir la rubrique « Écart à corriger » de chaque source.
2. **Pertinence** : la source dit bien ce que les phrases du rapport lui font dire. **Non vérifié** : c'est l'objet de la signature.

Sources citées dans le rapport : 14. Pré-vérification faite par l'agent ; contrôle humain : à faire.

Une fois une fiche signée, inscrire dans `docs/design/rapport-cabinet/references-autorisees.json`, sur la ligne de la référence : `"statut": "source contrôlée", "controlee_par": "<nom>", "controlee_le": "AAAA-MM-JJ"`, puis régénérer le rapport. Le bandeau et la colonne « Source contrôlée » se mettent à jour seuls.
